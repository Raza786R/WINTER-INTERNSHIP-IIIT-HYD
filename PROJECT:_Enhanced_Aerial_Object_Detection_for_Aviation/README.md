# ENHANCED AERIAL OBJECT DETECTION FOR AVIATION
**Final Internship Project - IIIT Hyderabad**

This project focuses on identifying UAVs in diverse aerial environments to improve aviation safety. Using **YOLOv8s** and **Transfer Learning**, I achieved professional-grade detection accuracy.

### 📊 Performance Summary
- **mAP50:** 99.4%
- **Precision:** 98.9%
- **Recall:** 99.1%

### 📂 Folder Structure:
- **/weights**: The final trained "best.pt" model.
- **/metrics**: Training results and performance curves.
- **/data**: Dataset configuration (data.yaml).
